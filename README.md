# Học lịch sử — Thành cổ Quảng Trị 1972 (sa bàn 3D web)

Sa bàn 3D tương tác (three.js) cho mục "Không gian lịch sử" của site Việt Sử. Tái dựng mô phỏng, cần đối chiếu tư liệu.

- **Chạy trên máy:** `cd web && python3 -m http.server 8000` → mở http://localhost:8000
- **Bản xem online:** GitHub Pages (tự cập nhật sau mỗi lần merge vào `main`).
- **Tài liệu:** [`docs/TOM_TAT.md`](docs/TOM_TAT.md) (trạng thái dự án) · [`docs/QUY_TRINH.md`](docs/QUY_TRINH.md) (cách làm việc chung)
- **Cho AI:** [`AGENTS.md`](AGENTS.md) (ChatGPT/Codex) · [`CLAUDE.md`](CLAUDE.md) (Claude)
