# Việt Sử V3.1

Cập nhật giao diện mobile 5 menu cùng hàng, logo trong thanh trên; chỉ hiện icon của Giao diện sáng/tối và Đăng ký/Đăng nhập ở mobile. Popup mặc định Full, chia sẻ sang hàng riêng, tên triều đại có Hán tự. Trang dòng thời gian thay các nút dưới tiêu đề bằng tìm kiếm tra cứu nhân vật, triều đại, bài học và sự kiện; bộ lọc đối chiếu giữ ở ngay trên nội dung timeline. Menu SGK không lưu màu lựa chọn khi chuyển sang menu lớn khác.

Bản HTML offline được nhúng trực tiếp, CMS giữ API /api/site-config, các cấu hình SEO và đường dẫn bài viết từ V3.0.
